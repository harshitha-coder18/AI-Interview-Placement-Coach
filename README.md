# AI Interview & Placement Coach 🚀

An AI-powered full-stack platform designed to help students prepare for coding interviews, improve DSA skills, and track placement preparation.

## ✨ Features

- 🔐 Secure Authentication using JWT & Password Hashing
- 🤖 AI-based Mock Interview Practice
- 📄 Resume Analysis & Feedback
- 💻 DSA Progress Tracking
- 🏢 Company-wise Interview Preparation
- 📊 Personalized Learning Dashboard

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication

### AI Integration
- AI APIs for interview simulation and feedback
